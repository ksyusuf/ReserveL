# ReserveL - Son Değişiklikler

## **Son Güncellemeler (no_show_check branch)**




- ### İşletme kayıt ve giriş işlemleri eklendi.

- ### Bu isteğin dönüş değerini de istediğimiz formata getiremediğimiz için kontrat fonksiyonunun dönüş değerini simülasyondan alıyoruz.

- ### Veritabanına işletme modelleri eklendi.


- ### İşletme kayıt ve giriş sayfaları ui düzenlemesi yapılacak.

- ### İşletme kaydı yapılırken uygulanması gereken akış, register page içerisinde todo olarak belirtildi.


## Not

- ### Bazı şeyler stellar tarafında değiştirildi ya da başka bir şeyler oldu, program bozulmuştu ama şimdilik çalışıyor.

- ### *pollTransaction* nedense bozulmuş vaziyette, artık onun yerine *getTransaction*'a manuel istek atıyoruz.
